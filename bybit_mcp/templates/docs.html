服务支持 OAuth 2.1 授权码、PKCE S256、CIMD 客户端元数据、动态客户端注册、资源绑定、刷新和撤销。先在后台录入账户密钥并生成授权 Token；OAuth 页面只输入 Token，验证可用操作后批准。API Key 和 Secret 不会返回给 MCP 客户端。

直接 Bearer 接入

支持自定义请求头的 MCP 客户端，可直接使用后台生成的授权 Token，无需 OAuth 登录。

Authorization: Bearer bbm_auth_…

环境、具体密钥、允许操作、有效期和撤销规则相同。OAuth 方式仍可使用；管理登录 Token 专用于后台。

先用 Demo

  1. 登录 Bybit 主站，切换到 Demo Trading，在模拟账户中创建 API 密钥。
  2. 在后台“账户连接”录入 Demo 密钥，再到“授权 Token”选择环境、具体连接、允许操作和有效期（可设无限期）。
  3. 连接 MCP，在 OAuth 页面填写授权 Token，验证回显后批准。调用 bybit_list_connections 与 bybit_get_profile 确认环境；调用 bybit_get_wallet 查询余额。
  4. 使用 bybit_get_instruments 检查精确合约，再通过下单工具提交。API 接受订单后，请查询订单或成交确认状态。

Demo 与 Testnet 不通用。Demo 只开放 Bybit 官方支持的接口；不支持 WS Trade，交易通过 REST 完成。

多环境与多密钥

一个 Token 可以绑定多个环境和多组密钥，并按连接单独配置权限类别及具体操作。多连接授权的写入调用必须传入 connection_id；默认连接只用于读取。后台扩大权限后，客户端须重新授权；缩减、到期、撤销则对后续调用生效。

无限期指授权 Token 的有效期。OAuth 访问令牌仍为短期，并通过刷新轮换续期。Token 不可直接作为管理登录凭证或 MCP Bearer。定时撤单要求 Token、OAuth 授权和相关连接持续有效，失效后的未成交委托须在后台处理。
